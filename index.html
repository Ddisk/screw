01 / 07
LOAD PATH / 02

軸方向と横方向では、力の受け方が違う

この教材は「同じボルト n 本で、中心にかかる静荷重を均等に分担する」モデル。

軸方向：部品を引き離す P

1本分の外力 p = P / n

締付力があるため、離間するまでは
p の一部だけがボルト軸力に加わる。

横方向：部品をずらす Q

摩擦で保持 ／ 軸で直接受ける

摩擦接合：接合面の摩擦が横荷重を支える。
直接せん断：ボルト断面で横荷重を受ける。

偏心荷重・モーメント・こじりがあると均等分担にならない。P / n、Q / n をそのまま使わず、最大負担ボルトを求める。
02 / 07
AREA & STRENGTH / 03

ネジ山がある部分は、呼び径の丸棒より弱い

引張には、有効断面積 Aₛ を使う

Aₛ ≈ π / 4 × (d − 0.9382pₜ)²

d：呼び径 [mm]　pₜ：ピッチ [mm]
Aₛ：引張応力を計算する有効断面積 [mm²]

引張応力 σ = Fᵦ / Aₛ

Fᵦ：1本のボルト軸力 [N]
1 N/mm² = 1 MPa。N と mm でそろえる。

強度区分の数字を読む

8.8 → 公称引張強さ 800 MPa
公称降伏応力 800 × 0.8 = 640 MPa

区分公称引張公称降伏
4.6400240

10.91,000900
12.91,2001,080

単位：MPa。本教材は数字から求めた公称降伏値を比較基準 S に使用。規格の最小耐力・保証荷重応力とは区別する。

安全率 s = S / σ

実設計では径・製品・規格に適した保証値を使用。ステンレスの A2-70 などには、この区分を適用しない。

03 / 07
PRELOAD / 04

締付力 ＋ 外力の一部 ＝ ボルトの軸力

① トルクから締付力を概算

Fᵢ ≈ 1000 T / (K d)

T：1本の締付トルク [N·m]
K：トルク係数　d：呼び径 [mm]

K はネジ面・座面の摩擦などで変わる。
同じ T でも K が小さいと Fᵢ は大きくなる。

② 外力の分担を、ばねで考える

C = kᵦ / (kᵦ + k꜀)

kᵦ：ボルトのばね定数
k꜀：締結部品の圧縮ばね定数

C は内外力比の簡略モデル。実際は荷重の作用位置や部品形状も影響する。教材では C を直接指定する。

接合面が閉じている間

Fᵦ = Fᵢ + C p
F꜀ = Fᵢ − (1 − C) p

Fᵦ：ボルト軸力 [N/本]
F꜀：残っている押付力 [N/本]

例えば C = 0.2 なら、外力の20%が軸力増加、80%が押付力の減少に回る。

F꜀ = 0 になると、離間する

pₛₑₚ = Fᵢ / (1 − C)

離間後：Fᵦ = p、F꜀ = 0

離間後も Fᵢ + Cp を延長しない。
変形は線形弾性を仮定。降伏後の変形は扱わない。

締め付けを強めると離間・滑りを抑えやすいが、ボルトの引張余裕は減る。締め過ぎても良くない。

05 / 07
SHEAR & MARGIN / 06

「滑らない」と「ボルトが切れない」は別の判定

摩擦接合モード

残っている押付力で、横荷重を支える。
接合面1面・全ボルトの押付力を合計。

Qₗᵢₘ = μ n F꜀
s滑り = Qₗᵢₘ / Q

μ：接合面の摩擦係数
K：トルク係数とは別の値。

s離間 = n Fᵢ / {(1 − C) P}

s離間 = 1 で離間開始。s滑り = 1 で滑り限界。P = 0 または Q = 0 のとき、それぞれの判定は対象外。

滑り限界を超えた後の穴当たり・衝撃は計算しない。モードを切り替えても、実際の滑り後の挙動を再現するわけではない。

直接せん断モード

横荷重の全量をボルトで均等に受ける。
せん断面はねじ無し軸部・1面に限定。

A = π d² / 4
τ = Q / (n A)

引張とせん断が同時に作用するとき：

σₑ = √(σ² + 3τ²)
s合成 = S / σₑ

延性材料の降伏をみるミーゼス相当応力の簡易評価。引張には Aₛ、せん断には軸断面積 A を用いる保守的な比較。ねじ部がせん断面にある場合や、各断面の詳細評価は対象外。

教材の判定：選択モードの各安全率 ≥ 設定した必要安全率。必要安全率の初期値1.5は操作例であり、推奨設計値ではない。

WORKED EXAMPLE / 07

M8 × 4本なら、どう計算する？

標準例：8.8 ／ T = 10 N·m ／ K = 0.20 ／ C = 0.20 ／ μ = 0.20
全体引張 P = 8 kN ／ 全体横荷重 Q = 2 kN ／ 必要安全率 = 1.5

1本あたりの力を求める

① 締付力：1000 × 10 / (0.2 × 8)
Fᵢ = 6,250 N

② 外力：8,000 / 4 = 2,000 N

③ 軸力：6,250 + 0.2 × 2,000
Fᵦ = 6,650 N

④ 押付力：6,250 − 0.8 × 2,000
F꜀ = 4,650 N

⑤ 引張応力：6,650 / 36.61
σ ≈ 181.6 MPa

摩擦接合として判定する

引張：640 / 181.6 ≈ 3.52

離間：(4 × 6,250) / (0.8 × 8,000)
≈ 3.91

滑り：(0.2 × 4 × 4,650) / 2,000
= 1.86

このモデルでは、すべて1.5以上

小さいのは滑りの余裕。ボルトの材料強度だけを高めても、同じ締付力なら滑り耐力は増えない。

計算範囲：常温・静荷重・同一ボルトの均等分担。疲労、緩み、ねじ山の抜け、座面の陥没、穴の面圧、曲げ、締付時のねじり、締付力のばらつき・低下は別途確認する。

式の参考：NASA Fastener Design Manual ／ SOLIDWORKS 有効断面積
