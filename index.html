力の向きによって、確認することが変わる

「引き離す力」と「横にずらす力」を分けて考えます。

引張：部品を引き離す

ボルトが強く引っ張られます。
伸びすぎないか、接合面が開かないかを確認します。

横荷重：部品をずらす

最初は接合面の摩擦が抵抗。
軸で直接支える設計では、ボルトのせん断も確認します。

例えば：吊り下げ用のボルトには引張。壁に固定したブラケットには横荷重や曲げが作用します。実物でどの向きに力が流れるかを確認します。

ボルト軸力は「締付力＋外力の一部」

同じボルトn本・中心荷重・均等分担・線形弾性を仮定します。

トルクから締付力を概算

Fᵢ ≈ 1000 T / (K d)

T：1本の締付トルク [N·m]
d：呼び径 [mm] ／ K：トルク係数
1000はN·mをN·mmへ換算する係数。

外力を1本分にする

p = P / n
C = kᵦ / (kᵦ + k꜀)

P：全体引張外力 [N] ／ n：本数
kᵦ：ボルトのばね定数
k꜀：締結部品の圧縮ばね定数
Cは荷重位置の影響などを省いた内外力比。

接合面が閉じている間

Fᵦ = Fᵢ + C p
F꜀ = Fᵢ − (1 − C) p

Fᵦ：1本のボルト軸力 [N]
F꜀：1本分の残存押付力 [N]

離間する境界

pₛₑₚ = Fᵢ / (1 − C)

離間後は Fᵦ = p、F꜀ = 0。

離間後に Fᵢ + Cp を延長しません。
Kは摩擦状態に依存し、締付力にはばらつきが生じます。

強く締めると離間・滑りを防ぎやすくなりますが、ボルトの引張余裕と座面の面圧余裕は減ります。

横荷重は「滑り」と「直接せん断」を分ける

横荷重をどこで受ける設計かによって、使う式を切り替えます。

摩擦接合：面で支える

Qₗᵢₘ = μ n F꜀
s滑り = Qₗᵢₘ / Q

Q：全体横荷重 [N]
μ：接合面の摩擦係数（Kとは別）
接合面1面、全ボルトの押付力を合計。

離間の余裕も確認

s離間 = n Fᵢ / {(1 − C) P}

1で離間開始。荷重ゼロ時は対象外。
滑った後の穴当たりや衝撃は計算しません。

直接せん断：軸で支える

A = π d² / 4
τ = Q / (n A)

ねじ無し軸部・せん断1面に限定。
横荷重の全量をボルトが均等に受ける仮定。

σₑ = √(σ² + 3τ²)
s降伏 = Sᵧ / σₑ

σ = Fᵦ/Aₛ と τ を組み合わせた保守的な簡易評価。Sᵧは規格の最小降伏応力・耐力等を使用。保証荷重応力は純引張の評価に使用します。

偏心・曲げ・こじり・疲労は別評価。必要安全率の初期値1.5は教材用の設定であり、用途共通の推奨値ではありません。
