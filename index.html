01 / 07
LOAD PATH / 02

軸方向と横方向では、力の受け方が違う

この教材は「同じボルト n 本で、中心にかかる静荷重を均等に分担する」モデル。

軸方向：部品を引き離す P

1本分の外力 p = P / n

締付力があるため、離間するまでは
p の一部だけがボルト軸力に加わる。

横方向：部品をずらす Q

摩擦で保持 ／ 軸で直接受ける

摩擦接合：接合面の摩擦が横荷重を支える。
直接せん断：ボルト断面で横荷重を受ける。

偏心荷重・モーメント・こじりがあると均等分担にならない。 P / n、Q / n をそのまま使わず、最大負担ボルトを求める。
02 / 07
AREA & STRENGTH / 03

ネジ山がある部分は、呼び径の丸棒より弱い

引張には、有効断面積 Aₛ を使う

Aₛ ≈ π / 4 × (d − 0.9382pₜ)²

d：呼び径 [mm]　pₜ：ピッチ [mm]
Aₛ：引張応力を計算する有効断面積 [mm²]

引張応力 σ = Fᵦ / Aₛ

Fᵦ：1本のボルト軸力 [N]
1 N/mm² = 1 MPa。N と mm でそろえる。

強度区分の数字を読む

8.8 → 公称引張強さ 800 MPa
公称降伏応力 800 × 0.8 = 640 MPa

単位：MPa。本教材は数字から求めた公称降伏値を比較基準 S に使用。 規格の最小耐力・保証荷重応力とは区別する。

安全率 s = S / σ

実設計では径・製品・規格に適した保証値を使用。 ステンレスの A2-70 などには、この区分を適用しない。

03 / 07
PRELOAD / 04

締付力 ＋ 外力の一部 ＝ ボルトの軸力

① トルクから締付力を概算

Fᵢ ≈ 1000 T / (K d)

T：1本の締付トルク [N·m]
K：トルク係数　d：呼び径 [mm]

K はネジ面・座面の摩擦などで変わる。
同じ T でも K が小さいと Fᵢ は大きくなる。

② 外力の分担を、ばねで考える

C = kᵦ / (kᵦ + k꜀)

kᵦ：ボルトのばね定数
k꜀：締結部品の圧縮ばね定数

C は内外力比の簡略モデル。 実際は荷重の作用位置や部品形状も影響する。 教材では C を直接指定する。

接合面が閉じている間

Fᵦ = Fᵢ + C p
F꜀ = Fᵢ − (1 − C) p

Fᵦ：ボルト軸力 [N/本]
F꜀：残っている押付力 [N/本]

例えば C = 0.2 なら、外力の20%が軸力増加、 80%が押付力の減少に回る。

F꜀ = 0 になると、離間する

pₛₑₚ = Fᵢ / (1 − C)

離間後：Fᵦ = p、F꜀ = 0

離間後も Fᵢ + Cp を延長しない。
変形は線形弾性を仮定。降伏後の変形は扱わない。

締め付けを強めると離間・滑りを抑えやすいが、 ボルトの引張余裕は減る。締め過ぎても良くない。
